일회용 인공눈물, 뚜껑을 다시 닫아도 될까? 남은 액·용기 처리 확인법

작성: 케어로컬 사이트 운영자 · 내용 수정 요청

일회용 인공눈물은 액이 남거나 뚜껑을 다시 닫을 수 있어도 여러 번 쓰는 제품으로 판단하면 안 됩니다. 포장의 1회용 표시와 해당 제품의 사용 안내를 확인하세요. 일회 사용 뒤 남은 액·용기를 버리라는 제품을 냉장 보관이나 재밀봉만으로 다시 사용하지 않습니다.

핵심 구분자료 확인실행 순서공식 안내

닫히는 뚜껑이 다회용의 근거는 아닙니다

리캡 형태는 개봉한 윗부분을 다시 끼울 수 있는 용기 구조를 말합니다. 손으로 다시 닫을 수 있다는 사실과 개봉한 약을 재사용해도 된다는 허가사항은 다릅니다. 식약처의 일회용 점안제 안전사용 안내도 이 혼동을 설명합니다.

포장·사용설명서의 제품명과 1회용 표시를 먼저 확인하세요. 병 모양이나 한 번 쓰고도 남는 양만으로 구분하지 않습니다. 같은 성분의 다른 용기·농도 제품을 검색했다면 그 사용법을 내 제품에 옮기지 마세요.

개봉 전 사용기간과 개봉 후 처리 기준을 나눠 봅니다

확인 항목볼 자료혼동하지 않을 것
확인 항목제품의 1회용 여부볼 자료원포장·제품명·설명서혼동하지 않을 것다시 닫히는 뚜껑 형태
확인 항목남은 액과 용기볼 자료본인 제품의 용법·주의사항혼동하지 않을 것냉장하면 재사용 가능하다는 추정
확인 항목개봉 전 보관볼 자료보관조건·포장 사용기간혼동하지 않을 것표시 사용기한까지 개봉액을 보관
확인 항목다른 안약·렌즈와 사용볼 자료해당 제품 안내·처방혼동하지 않을 것다른 제품의 점안 간격을 그대로 적용

현재 식약처의 셀론점안액(1회용) 허가정보는 일회 사용 후 재사용하지 말고 남은 액과 용기를 버리도록 명시합니다. 제품코드 202301382를 확인하는 예시이며 특정 제품을 추천하거나 모든 안약의 용법을 대신하는 안내가 아닙니다.

여러 안약을 함께 쓰거나 콘택트렌즈를 사용하는 경우 간격·착용 조건은 각 제품과 처방에 맞춰 약사에게 확인하세요. 이 글의 주제는 개봉 후 재사용 판단이므로 일률적인 방울 수나 점안 간격을 처방하지 않습니다.

포장과 설명서를 이렇게 확인하세요

  1. 정확한 제품명·농도·업체와 1회용 표시를 확인합니다.
  2. 용법·용량, 사용 후 처리와 보관 안내를 읽습니다.
  3. 처음 여는 용기인지 이미 사용한 용기인지 구분합니다.
  4. 재사용 금지 제품은 남은 양이나 뚜껑 모양만 보고 보관하지 않습니다.
  5. 문구가 불분명하면 원포장과 설명서를 갖고 약사에게 문의합니다.

사용 후 처리 안내와 지역 폐의약품 수거 방식은 따로 확인할 내용입니다. 남은 약액을 싱크대·변기에 흘려보내거나 다른 용기에 모아 재사용하지 마세요. 미사용·남은 의약품의 배출은 거주 지역이나 수거 창구의 안내를 따릅니다.

가상 예시: 뚜껑이 다시 닫혀 헷갈리는 경우

수연 씨는 일회용 안약에 액이 남아 뚜껑을 다시 끼우려다가 제품 표시를 확인했습니다. 재사용하지 말라는 안내를 보고, 개봉 전 보관 조건과 사용 뒤 처리 안내를 구분합니다. 이는 특정 제품의 치료 효과가 아닌 표시 확인을 설명하는 가상 상황입니다.

문의할 때 사용할 문장

현재 ○○점안액 ○% 제품을 사용합니다. 포장에는 ○○라고 적혀 있고 용기 뚜껑이 다시 닫힙니다. 이 제품의 일회 사용 후 잔액·용기 처리와 개봉 전 보관 기준을 확인해 주세요. 다른 안약이나 렌즈 관련 주의도 제 제품에 맞춰 알고 싶습니다.

통증·시야 변화나 지속되는 충혈 등 이상이 생기면 재사용 여부만 검색하며 기다리지 말고 의료진·약사에게 상담하세요. 이미 사용한 용기를 언제 열었는지와 제품명을 함께 알리면 상담에 도움이 됩니다.

함께 궁금할 수 있는 점

미개봉 제품도 바로 버려야 하나요?

미개봉 제품의 보관조건·사용기간과 일회 사용 뒤 처리는 다른 기준입니다. 미개봉 상태는 본인 제품의 포장·설명서와 약사의 안내를 따르세요.

다회용 안약도 한 번 쓰고 버리나요?

이 글을 다회용 안약에 그대로 적용하지 않습니다. 다회용은 해당 제품의 개봉 후 사용·보관 안내를 별도로 확인해야 합니다.
