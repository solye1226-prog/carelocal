처방전 질병코드 누락, 실비 청구 대체서류와 재발급 확인

처방전에 질병코드(질병분류기호)가 누락됐다면 실비 청구에 필요한 진단명 확인 자료를 보험사에 먼저 문의하세요. 기존 진료 자료로 대체할 수 있는지 확인한 뒤, 필요할 때 병원에 실제 기록에 따른 정정·재발급을 요청합니다. 질병코드를 직접 찾아 처방전에 적거나 고치지 않습니다.

처방전 질병코드 누락 시 보험사에 확인할 항목

KB손해보험 질병 청구서류에서 코드 기재와 담보별 자료를 확인할 수 있습니다. 질병코드는 의료기관의 실제 진단 기록을 확인하기 위한 정보이며, 코드 하나만으로 보험금 지급을 결정하지 않습니다.

KB손해보험 공식 질병 청구서류 안내는 질병분류코드가 기재된 처방전 등 진단명 확인 자료를 안내합니다. 현대해상 공식 청구서류 안내도 처방전의 질병분류코드가 없으면 추가 증빙이 필요할 수 있다고 설명합니다. 회사·청구 건마다 대체자료가 같다고 가정하지 말고 어떤 정보가 누락됐는지부터 확인하세요.

실비 대체서류: 병원 자료와 약국 영수증 구분

병원 진료비 영수증·세부내역서와 약국 약제비 영수증·처방전은 발급처가 다릅니다. 진단명 확인을 위해 진료확인서가 필요한지, 기존 의무기록으로 충분한지는 보험사에 물어본 뒤 발급받으세요.

질병분류기호 정정·재발급은 병원에 문의

처방전에 누락이 있다면 병원에 정정 또는 재발급 가능 여부를 문의합니다. 의료기록의 진단명이나 질병분류기호를 환자가 임의로 바꾸면 사실관계 확인이 어려워집니다.

처방전 코드 누락 보완서류 제출 순서

  1. 보험사가 요청한 진료일과 누락 항목을 확인합니다.
  2. 처방전과 기존 진료 자료에 진단명·질병분류기호가 있는지 대조합니다.
  3. 대체 문서 인정 여부를 문의한 뒤 병원에 실제 기록에 맞는 자료를 요청합니다.

처방전 사본을 보관용으로 받는 것과 약국 조제에 쓸 새 처방전을 받는 것은 목적이 다릅니다. 보험 보완에 필요한 문서 종류를 먼저 확인하세요. 질병분류기호를 직접 검색해 원본 문서에 적어 넣지 않습니다.
