처방전에 질병분류기호가 빠졌다면 어떻게 할까?

통원 치료비와 약제비를 함께 청구하는데 처방전에 질병분류기호가 보이지 않는다면, 보험사에 대체 가능한 진료 자료가 있는지 먼저 물어보세요. 임의로 코드를 적어 넣어서는 안 됩니다.

서류·치료 구분의 근거를 공식 원문에서 확인하세요.

삼성화재 담보별 청구서류 확인공식 안내에서 본인의 실손·수술 담보 항목 선택 · 새 창 ↗

보험사별 서류와 가입 약관의 지급 기준은 다를 수 있습니다.

이미지는 이해를 돕기 위한 생성 장면으로 실제 환자나 의료기록이 아닙니다. 보장 여부·서류·지급액은 가입 상품, 약관, 실제 치료 기록과 보험사 심사에 따라 달라집니다.
보험사별 공식 홈페이지 확인하기

요청받은 항목을 정확히 묻습니다

삼성화재 통원 실손 안내는 질병분류기호가 적힌 처방전을 기본 서류 예시로 듭니다. 하지만 모든 보험사와 모든 청구에서 같은 서식만 인정하는 것은 아니므로, 접수 건의 보완 사유를 먼저 확인합니다.

병원과 약국 서류를 나눕니다

병원 진료비 영수증·세부내역서와 약국 약제비 영수증·처방전은 발급처가 다릅니다. 진단명 확인을 위해 진료확인서가 필요한지, 기존 의무기록으로 충분한지는 보험사에 물어본 뒤 발급받으세요.

기존 서류를 수정하지 않습니다

처방전에 누락이 있다면 병원에 정정 또는 재발급 가능 여부를 문의합니다. 의료기록의 진단명이나 질병분류기호를 환자가 임의로 바꾸면 사실관계 확인이 어려워집니다.

코드 누락으로 보완 요청을 받았다면

  1. 보험사가 요청한 진료일과 누락 항목을 확인합니다.
  2. 처방전과 기존 진료 자료에 진단명·질병분류기호가 있는지 대조합니다.
  3. 대체 문서 인정 여부를 문의한 뒤 병원에 실제 기록에 맞는 자료를 요청합니다.

처방전 사본을 보관용으로 받는 것과 약국 조제에 쓸 새 처방전을 받는 것은 목적이 다릅니다. 보험 보완에 필요한 문서 종류를 먼저 확인하세요. 질병분류기호를 직접 검색해 원본 문서에 적어 넣지 않습니다.
