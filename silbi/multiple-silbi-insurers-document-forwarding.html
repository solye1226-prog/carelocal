실손보험 여러 개 청구, 서류 한 번만 내고 전송할 수 있을까?

작성·보완: 케어로컬 사이트 운영자 · 내용 수정 요청

실손의료비 보험이 여러 회사에 있다면 한 회사가 청구서류를 다른 회사로 전송해 주는 서비스를 제공하는지 확인하세요. 서류 전송과 보험금 지급 결정은 별도 단계입니다.

가입 회사와 계약 종류를 먼저 적습니다

같은 치료비를 여러 실손계약에 청구하려는 경우 계약별 보장 기간과 피보험자를 확인합니다. 정액 수술비·진단비는 실손 서류 전송 서비스와 대상이 다를 수 있습니다.

서류 전송 신청 여부를 확인합니다

손해보험협회 안내의 청구서류 접수대행은 최초 접수 보험사에 신청하는 방식입니다. 협회에 직접 보험금 서류를 제출하는 서비스가 아닙니다. 실손24의 전자 전송과도 출발점이 다릅니다.

방법보내는 경로와 확인할 점
방법보험사 접수대행보내는 경로와 확인할 점최초 접수 보험사에 대상 계약과 신청 가능 범위를 확인합니다. 전달 후 각 회사의 접수번호를 확인합니다.
방법실손24보내는 경로와 확인할 점선택한 의료기관의 진료 자료를 보험사로 전송합니다. 조회되는 기관·진료일·문서와 대상 보험사를 확인합니다.
방법회사별 앱 직접 접수보내는 경로와 확인할 점각 회사에서 접수번호와 보완 요청을 따로 확인합니다. 중복 제출 전에 기존 건 반영 여부를 확인합니다.

서류를 같이 보낼 수 있는지와 각 계약에서 무엇을 보장하는지는 별개입니다. 유병자 실손의 약값 제외 여부처럼 계약별 보장 범위가 다를 수 있고, 여러 실손에 가입했다고 같은 손해를 중복 보상받는 것은 아닙니다.

전송 후에는 회사별 접수 상태를 봅니다

한 곳에서 전송했다는 알림만으로 모든 회사에서 심사가 시작됐다고 단정하지 마세요. 각 보험사의 접수번호, 추가서류 요청, 지급 내역을 따로 확인합니다. 실손의 중복 가입과 실제 보상액의 관계는 본인 약관을 확인하세요.

전송 후 회사별로 확인할 것

  1. 실손 계약의 회사명·피보험자·보장기간을 정리합니다.
  2. 전송 대상 회사와 필요한 신청·동의 서류를 공식 접수처에서 확인합니다.
  3. 회사마다 접수번호·추가서류 요청·지급 상태를 따로 확인합니다.

한 회사의 전송 완료 알림은 다른 회사의 보험금 지급 승인을 뜻하지 않습니다. 여러 실손 계약의 동일 비용 청구는 각 계약의 정산 규칙을 따릅니다. 정액 수술비까지 같은 서비스로 전송되는지는 별도로 문의하세요.
