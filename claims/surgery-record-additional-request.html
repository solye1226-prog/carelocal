수술기록지 추가 요청, 무엇부터 확인할까?

수술확인서를 이미 제출했는데 수술기록지를 요청받았다면 요청 사유와 필요한 진료일·기재 항목부터 확인하세요. 수술기록지 전체를 무조건 선발급하기보다 어떤 수술 행위를 확인하려는지 보험사에 묻고 병원에 해당 기록의 사본을 신청하면 됩니다.

이미지는 이해를 돕기 위한 생성 장면으로 실제 진료기록이 아닙니다. 보험금 지급 여부와 필요서류는 가입 상품·약관, 실제 치료 내용과 보험사 심사에 따라 달라집니다.

동시 시행한 행위퇴원요약지·세부내역서각 행위의 시행일이 필요한가요?
담보의 수술 정의가입 당시 약관어느 특약·조항 심사에 필요한가요?

진료비 세부내역서의 행위코드가 여러 개여도 보험의 종수나 지급 횟수가 자동 결정되지는 않습니다.

병원에는 기록의 범위를 지정하세요

의료법 제21조에 따라 환자는 본인 기록의 전부 또는 일부에 대한 열람이나 사본 발급을 요청할 수 있습니다. 병원별 접수 절차와 발급 비용은 확인하세요. 수술 날짜, 진료과, 수술기록 사본이라는 범위를 알려주면 필요한 자료를 찾기 쉽습니다.

본인이 아닌 사람이 신청한다면 별도 자격·동의·위임 서류가 필요할 수 있습니다. 민감한 수술기록을 공개 게시판이나 일반 채팅방에 올리지 말고 보험사 공식 제출 경로를 사용하세요.

제출 후에는 적용 근거를 확인하세요

  1. 요청 문자·앱 알림과 접수번호를 보관합니다.
  2. 보험사가 필요한 항목과 대체자료 가능 여부를 답한 내용을 기록합니다.
  3. 병원 기록에 실제 시행한 수술명·일자가 있는지 확인합니다.
  4. 심사 결과에서 적용한 약관 조항과 분류표 항목을 확인합니다.

추가 서류 요청 자체가 보험금 부지급을 뜻하지는 않습니다. 기록이 달라 보인다면 의료기관에 사실관계를 확인하세요.
