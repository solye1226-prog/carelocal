# 기존 핵심 대표 글 6편 보완

## 범위와 순서

담낭절제술 → ERCP → 백내장 종수 → 수술분류표 → 카티스템 실비 → 카티스템 치료비 순서로 보완했다. 신규 글을 만들지 않았으며 검색어 자료를 특정 URL의 클릭 통계로 취급하지 않았다.

## 주요 변경

- 담낭·백내장: 반복되는 공통 서류 표를 정리하고 이미 있는 담보별 서류 안내로 연결. 담낭의 운영 표현인 검색 유입 질문 문구 제거. 진료행위 코드로 종수를 추정하지 않도록 실제 기록 대조에 집중.
- ERCP: 시행일·검사/치료 목적·실제 행위·동반/후속 치료의 확인 메모를 추가.
- 백내장: 수술 분류·양안 지급 횟수·실손 비용을 나누어 문의하는 표와 질문 문장 제공.
- 수술분류표: 기존 문의 메모의 반복을 정리하고 계약·수술·분류 근거·지급 단위 빈칸을 제공. 실제 계약의 종수를 만들어 넣지 않음.
- 카티스템: 제품 비용과 약제·행위·치료재료 항목을 구분하도록 설명 보완. 치료 필요성 보완 요청 범위와 치료 전 견적의 포함 항목을 구체화.
- 카티스템 기존 출처의 일반 동향 PDF를 실제 식약처 품목 상세정보로 교체. 품목명과 효능효과를 해당 원문의 실제 응답에서 확인했다. 의료 허가와 보험 지급 판단은 구분.
- 공식 상세 버튼 총11개 추가. 병원 설명은 의료행위 구분, 보험사 자료는 해당 회사의 청구서류 예시로 범위를 표시.
- 문장이 잘린 관련 글 소개를 목적 글의 완결된 첫 답변으로 교체. 기존 후속10편으로 가는 링크 보존.
- 최근10편에서 검증한 읽기 스타일을 적용하고 문단·표 라벨을 정리. 카티스템 치료비 글에는 기존 관련 이미지3장을 추가했다.
- 제목·canonical·기존 이미지·최초 발행일을 보존했다. 최초 날짜가 없는 카티스템 치료비 글의 구조화 데이터에 임의 최초 발행일을 추가하지 않았다. 사이트맵은 실제 수정한6개 항목만10월13일로 변경.

## 검증과 공개

- `pnpm run check` 통과: HTML304개 링크, 사이트맵302개 대표 URL, 카탈로그277편, Python5개·Node10개 검사.
- 기존 제목·대표주소·이미지·후속 링크·원래 Article 발행일 보존6/6: `REINFORCE6_STATIC_2026-10-13.json`.
- 로컬 초기 렌더 검사6편×3개 폭18/18. 이후 핵심 도입부 분리와 메뉴 위치를 추가 조정했고 최종 공개본에서 다시 확인.
- 최종 공개6편×360·390·1440px18/18 통과: 이미지 로드·가로 넘침·최대 본문폭·공식 버튼 크기·앵커 동작.
- 공개 head·main 일치6/6, HTTP200·noindex 헤더 없음: `REINFORCE6_PUBLIC_BODY_2026-10-13.json`.
- 공개 PC·모바일 대표 화면 육안 확인. 광고 네트워크를 제외한 편집 콘텐츠 검사이며 실사용자 웹 지표나 광고 포함 전체 화면 검증은 아님.
- 콘텐츠 커밋 `ec62e19`, 사이트맵 수정 `6db33bc`. 색인 완료·검색 순위·수익 변화를 이번 검사로 주장하지 않음.

## 다음 판단

URL별 네이버 검색 노출·클릭·CTR을7일·28일로 확인한다. 기존 대표 글과 후속 글을 함께 비교하고, 노출은 늘지만 클릭이 적은 글부터 제목이 약속하는 답·첫 문단·서류 안내를 조정한다. 숫자 확인 없이 키워드별 CPC·경쟁도나 특정 글의 기여도를 확정하지 않는다.
