## 1. 담도 배액술 PTBD 수술비, ERCP·담낭절제술과 청구 기록은 어떻게 다를까?

- 세부키워드: PTBD 수술비, 담도 배액술 보험금, 담도 배액관 삽입 청구서류
- 기존 글과 차이: 내시경 ERCP나 담낭 절제가 아닌 피부·간을 통한 담도 배액의 실제 시행 기록. 단순 배액관 관리·제거·교체와 최초 시술을 나누며, 담낭 배액 PTGBD를 같은 명칭으로 섞지 않는다.
- 연결할 기존 글: https://hospital.hbuby.com/surgery-benefit/subtotal-cholecystectomy-insurance-documents, https://hospital.hbuby.com/surgery-benefit/gallbladder-ercp-combined-claim
- 본문 구성: PTBD·ERCP·담낭절제·PTGBD의 기록상 명칭과 대상 부위를 구분하는 표 → 시술 결과지·시행일·배액관 최초 삽입 사실을 찾는 순서 → 수술 정의·분류와 실손 비용을 각각 문의하는 문장
- 근거/확인처: https://www.knuh.kr/content/04information/06_05.asp?sh_d_num=12
- 발행 전 조건: 약어·튜브 유무만으로 종수나 지급을 정하지 않음. 다른 배액술과 비교할 경우 해당 병원 공식 자료를 별도로 확인.

## 2. 치루 세톤 수술 보험금, 설치·조임·제거 기록을 어떻게 나눌까?

- 세부키워드: 치루 세톤 수술비, 세톤 제거 보험금, 세톤 조임 수술확인서
- 기존 글과 차이: 치핵·치루 동시수술 또는 농양 배농 후 치루 수술과 달리 세톤 치료 과정의 날짜별 실제 행위와 수술·외래 처치 구분.
- 연결할 기존 글: https://hospital.hbuby.com/surgery-benefit/hemorrhoid-fistula-same-day-claim, https://hospital.hbuby.com/surgery-benefit/anal-fistula-surgery-benefit
- 본문 구성: 치료 전체 기간과 실제 시행 행위별 날짜표 → 설치·조임·제거라는 표현만으로 수술 횟수를 계산하지 않기 → 기존 접수내역과 각 방문 기록을 보험사에 문의하는 예시
- 근거/확인처: https://www.snuh.org/health/nMedInfo/nView.do?category=DIS&medid=AA000158
- 발행 전 조건: 서울대병원 치루 검색 자료에서 세톤법 존재 확인. 상세 페이지 웹 추출에서 해당 본문이 누락돼 발행 전 실제 본문 재확인 필요. 설치·조임·제거의 모든 경우를 수술로 일반화하지 않음.

## 3. 백내장 수술 렌즈 카드를 잃어버렸다면? 인공수정체 종류·수술 기록 확인법

- 세부키워드: 백내장 렌즈 카드 분실, 인공수정체 종류 확인, 렌즈 보증서 보험청구
- 기존 글과 차이: 다초점 렌즈 비용 보장이나 탈구 재수술 지급을 반복하지 않고 기존 삽입 제품의 정보를 어디서 확인하고 어떤 의료기록과 연결할지 안내.
- 연결할 기존 글: https://hospital.hbuby.com/surgery-benefit/iol-dislocation-reoperation-insurance, https://hospital.hbuby.com/claims/cataract-multifocal-lens-silbi
- 본문 구성: 렌즈 카드·제품 라벨·세부내역서·수술기록의 역할표 → 시행 병원에 제품명·모델·좌우 눈·시행일 확인을 요청하는 순서 → 카드와 진단·수술 사실 자료를 보험청구에서 구분하기
- 근거/확인처: https://patientimplantinfo.bausch.com/
- 발행 전 조건: 제조사 원문에서 카드의 기기·수술 정보 기록 역할 확인. 해외 제품 안내이므로 국내 모든 병원의 카드 발급 의무나 재발급 가능을 단정하지 않음. 카드만으로 지급된다고 쓰지 않음.

## 4. 카티스템·절골술 후 재활병원으로 옮겼다면? 실비 청구서류 나누는 법

- 세부키워드: 카티스템 재활병원 실비, 절골술 후 재활 입원 서류, 수술 후 전원 실비 청구
- 기존 글과 차이: 수술 당일 두 행위의 종수·비용이 아니라 수술병원 퇴원 뒤 다른 기관에서 받은 재활 진료의 자료와 접수. 기존 진료정보교류 글은 예약·기록 전송만 다룸.
- 연결할 기존 글: https://hospital.hbuby.com/surgery-benefit/cartistem-high-tibial-osteotomy-claim, https://hospital.hbuby.com/silbi/cartistem-silbi-claim
- 본문 구성: 수술병원·재활병원의 날짜 및 비용 묶음 분리 → 입퇴원 자료·진료의뢰·실제 치료내역의 용도 구분 → 실손 보장과 입원일당을 별개로 묻는 질문 양식
- 근거/확인처: https://nrc.go.kr/hospital/html/content.do?depth=mi&menu_cd=01_08_02
- 발행 전 조건: 국립재활원 안내는 병원 이용 자료의 후보이며 민간 실손 지급 기준이 아님. 발행 전 입원 필요성·보상 항목을 본문에 인용할 실제 약관 예시 확인. 특정 치료 후 재활 입원이 필수라고 쓰지 않음.

## 5. 수술이 취소됐는데 검사비·마취비가 나왔다면? 실비 청구 전 정산 확인

- 기존 글과 차이: 기존 수술 전 검사비 글은 날짜별 일반 청구. 새 글은 미시행·중단 시점, 실제 시행한 진료, 환불·정정 뒤 최종 본인부담을 구분하는 독립 상황.
- 연결할 기존 글: https://hospital.hbuby.com/surgery-benefit/hemorrhoid-pph-stapled-surgery-claim, https://hospital.hbuby.com/silbi/cataract-preoperative-test-claim, https://hospital.hbuby.com/claims/surgery-claim-documents
- 본문 구성: 수술 전 취소·마취 후 중단·일부 시행을 실제 기록으로 구분 → 예약금·취소수수료와 진료비 항목을 나누고 최종 정산액 확인 → 정액 수술비 질문과 실제 검사·마취 비용의 실손 질문을 분리
