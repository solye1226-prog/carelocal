## 1. 재활병원 입원 중 수술병원 외래를 가야 한다면? 진료의뢰·수납 확인 순서

- 중심 키워드: 입원 중 타병원 진료
- 세부 키워드: 재활병원 입원 중 외래 / 수술병원 추적진료 / 입원 중 타병원 진료비 정산
- 연결 글: `/silbi/knee-surgery-rehabilitation-hospital-transfer-claim`, `/guides/medical-information-exchange-consent-transfer`.
- 독립 질문: 전원 완료 후에도 입원을 유지하면서 원래 수술병원의 경과 진료가 필요한 경우, 방문 전에 누구에게 의뢰와 비용 처리를 확인할까?
- 구성: ① 전원과 입원 중 진료의뢰 구분 ② 병동 의료진·원무팀에 방문 전 확인 ③ 의뢰 내용·진료일·기관 간 정산 확인 ④ 이미 별도 결제했다면 양 기관에 정산 범위 문의 ⑤ 실제 비용이 확정된 뒤 민간보험 필요자료 확인.
- 실용 요소: 병동 문의 체크리스트, A병원 입원 중 B병원 추적진료 가상 예시, 두 기관의 안내를 대조하는 표.
- 중복 경계: 기존 재활 전원 글은 두 기관의 입원·치료 자료와 계약의 입원 요건을 설명한다. 이 글은 **입원 유지 상태에서 외부 진료를 받는 사전 의뢰 및 수납 절차**에 집중한다. 모든 진료를 기관별로 나눠 바로 청구하라고 쓰지 않는다.
- 공식 근거: [심평원 입원진료 중 타 요양기관 진료의뢰 FAQ](https://www.hira.or.kr/bbsDummy.do?brdBltNo=47404&brdScnBltNo=4&pgmid=HIRAA010006011400). 기관이 의뢰한 진료와 기관 간 정산을 설명한다. 자의적인 외출 진료·모든 기관 유형에 같은 결과를 적용하거나 민간 실손 지급 조항으로 바꾸지 않는다.

## 2. 치루 수술 후 소독·드레싱 비용, 외래 처치와 수술비를 어떻게 나눌까?

- 중심 키워드: 치루 수술 후 소독 실비
- 세부 키워드: 치루 드레싱 비용 / 치질 수술 후 통원 치료비 / 좌욕 단순처치 진료비
- 연결 글: `/surgery-benefit/anal-fistula-seton-staged-claim`, `/silbi/hemorrhoid-surgery-silbi-claim`.
- 독립 질문: 추가 수술이 아니라 상처 관리로 통원한 날의 진료비 항목과 제출자료는 어떻게 확인할까?
- 구성: ① 당일 시행한 진찰·처치·약값 확인 ② 좌욕·단순처치의 건강보험 산정 안내 ③ 실손 계약의 급여·비급여·공제 확인 ④ 방문일별 영수증·세부내역과 약국 자료 정리.
- 실용 요소: 수술 당일과 이후 외래일 비용 구분표, 실제 처치명 확인 질문, 방문별 자료 체크리스트.
- 중복 경계: 세톤 글은 설치·조절·제거의 추가 수술 인정과 횟수가 중심이고 통원 비용은 짧게 언급한다. 새 글은 **상처 처치의 비용 항목과 통원 청구**가 중심이다. 기존 가정간호 글의 서비스 신청·방문 처치 안내도 반복하지 않는다.
- 공식 근거: [심평원 치핵·치루 수술 후 좌욕·단순처치 동시 실시 급여기준](https://www.hira.or.kr/rc/insu/insuadtcrtr/InsuAdtCrtrPopup.do?mtgHmeDd=20180116&mtgMtrRegSno=0033&sno=3). 건강보험 기준과 민간 실손 보장은 구분한다.
- 발행 전 확인: 고시의 후속 개정·현행 여부와 적용 진료 상황을 다시 확인한다. 페이지 하단 **변경 전 7회 제한**을 현재 규정으로 인용하지 않는다. 실제 보험사의 현재 서류 안내와 본인 계약별 판단 범위를 추가 확보한다. 직접 상처를 소독하거나 세톤을 조절하는 방법은 다루지 않는다.
- 예정 경로: `/silbi/anal-surgery-outpatient-dressing-claim`.

## 3. 백내장 수술 후 MRI 예약, 인공수정체 제품 정보를 어디에 확인할까?

- 중심 키워드: 백내장 수술 후 MRI
- 세부 키워드: 인공수정체 MRI / 렌즈 카드 MRI 검사 / 인공수정체 모델 확인
- 연결 글: `/claims/iol-implant-card-lost-records`, `/silbi/mri-silbi-claim`.
- 독립 질문: 렌즈 정보를 확보한 다음 MRI 검사기관에는 무엇을 알리고 어떤 제품 자료를 전달할까?
- 구성: ① 삽입 기기·기타 체내 금속을 검사기관에 알림 ② 정확한 제조사·모델과 삽입 정보를 전달 ③ 제품별 사용설명서·MRI 안전정보를 검사팀이 확인 ④ 정보가 부족하면 검사기관과 수술병원에 확인.
- 실용 요소: MRI 예약 전 전달 메모, 모델 확인 여부별 문의 흐름, 국내 진료기관에 전달할 제품 정보 목록.
- 중복 경계: 렌즈 카드 분실 글의 카드 재확인 절차는 링크로 연결한다. 이 글의 결과물은 **검사 전 안전정보 전달과 확인 절차**다. MRI 실비·검사비 청구를 중심 답으로 반복하지 않는다.
- 공식 근거: [FDA MRI 전 환자 확인사항](https://www.fda.gov/radiation-emitting-products/mri-magnetic-resonance-imaging/what-patients-should-know-having-mri-exam), [Alcon 제품별 FAQ](https://www.alconscience.com/en-BR/patient/medical-info/faq/), [HumanOptics MRI 안내](https://www.humanoptics.com/en/mri/).
- 발행 전 확인: 제조사 FAQ는 해당 제품·국가 안내의 예시로 한정한다. 모든 인공수정체를 MRI 가능으로 일반화하지 않는다. 안전 여부의 최종 판단은 실제 제품 정보와 환자 상태를 확인한 검사기관이 한다. 국내 사용 제품은 국내 허가·사용설명서를 우선 보완한다.
- 예정 경로: `/guides/iol-mri-device-information-check`.

## 4. 담도 배액 후 배양검사 결과지를 받았다면? 조직검사와 다른 항목 확인법

- 중심 키워드: 담즙 배양검사 결과지
- 세부 키워드: 담도 배액 배양검사 / 배양검사 항생제 감수성 / 배양검사 조직검사 차이
- 연결 글: `/surgery-benefit/ptbd-biliary-drainage-insurance`, `/claims/gallbladder-pathology-request`.
- 독립 질문: 배액 시술 기록이나 조직병리 결과가 아닌 미생물 검사 자료를 요청받았을 때, 무엇을 확인해 어떤 자료를 준비할까?
- 구성: ① 배액 시술·조직병리·미생물 검사 자료의 역할 구분 ② 실제 검체 종류·채취일·검사명 확인 ③ 배양·동정과 감수성 결과의 구분 ④ 진료 설명과 보험사 요청 목적을 구분해 필요한 범위만 발급.
- 실용 요소: 검체·날짜·검사명 대조표, 병원 문의 문장, 조직검사 결과지를 잘못 제출한 가상 예시.
- 중복 경계: PTBD 글은 시술 자체의 사실과 수술비 판단이 중심이다. 담낭 조직검사 글은 병리 결과가 중심이다. 이번 글은 **미생물 검사 자료의 구분과 준비**에 한정한다. 모든 PTBD 환자가 배양검사를 받거나 보험사에 반드시 제출해야 한다고 쓰지 않는다.
- 공식 근거: [질병관리청 2026 복강내 감염 항생제 적정사용 실무지침](https://kdca.go.kr/bbs/kdca/55/306855/download.do), [심평원 배양 여부에 따른 약제감수성 검사 산정 안내](https://www.hira.or.kr/rc/insu/insuadtcrtr/InsuAdtCrtrPopup.do?mtgHmeDd=20171229&mtgMtrRegSno=0051&sno=3).
- 발행 전 확인: 질병관리청 원문에서 담도계 감염 부분의 정확한 페이지와 문맥을 확인한다. 수가 코드를 제시할 경우 현행 기준을 추가 확인한다. 결과의 S/I/R만으로 독자가 약을 선택·변경하도록 안내하거나 배양 결과 하나로 감염 진단을 확정하지 않는다. 보험 제출자료는 해당 회사 요청에 따르는 범위로 설명한다.
- 예정 경로: `/claims/bile-culture-vs-pathology-records`.

## 5. 수술 취소 후 예약금이 안 돌아온다면? 선납 진료비·검사비와 구분해 문의하기

- 중심 키워드: 수술 예약금 환불
- 세부 키워드: 병원 선납금 환급 / 수술 취소 계약금 / 검사비 제외 환불 내역
- 연결 글: `/silbi/cancelled-surgery-test-anesthesia-claim`, `/silbi/hospital-bill-correction-silbi-claim`.
- 독립 질문: 아직 돌려받지 못한 예약·선납금에 대해 병원에 정산 근거와 환급을 요청하려면 어떤 자료가 필요할까?
- 구성: ① 예약금·선납 진료비·이미 시행한 진료비 구분 ② 계약·설명·결제·취소 통지 자료 정리 ③ 공제항목·환급 산식의 서면 설명 요청 ④ 해결되지 않을 때 소비자상담·피해구제 경로 확인 ⑤ 환불 후 기존 보험금 접수가 있으면 정산 변경 알림.
- 실용 요소: 결제액·이미 받은 진료·공제 설명·환급액 대조표, 병원에 보낼 환급내역 요청문.
- 중복 경계: 수술 취소 실비 글은 취소 후 남은 실제 의료비의 보험 심사이고 예약금은 구분하라고 짧게 안내한다. 병원비 환불 후 실비 글은 환불 **이후 보험금 정산**이다. 이번 글은 **환불 전 병원과의 계약·정산 확인 및 상담 준비**가 중심이다.
- 공식 근거: [한국소비자원 선납진료비 피해예방 안내](https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1003881199&page=2), [한국소비자원 수술 예약금 관련 조정사례](https://www.kca.go.kr/odr/bj/br/osBjDecisionExamDetW.do?brdId=00000007&dataStts=Y&seq=1001222355).
- 발행 전 확인: 조정사례는 특정 성형수술 분쟁의 과거 사례다. 일반 질병 수술·병원 사정 취소·환자 사정 취소에 같은 환급률을 적용하지 않는다. **현행 분쟁해결기준의 적용 범위 및 공식 상담·접수 경로 확인 후 원고 확정**. 확정되지 않은 환급률·전액환급 권리·개별 법률판단을 제시하지 않는다.
- 예정 경로: `/treatment-costs/surgery-deposit-cancellation-refund-records`.

## 대조 결과와 후속 검수

- 전체 387편의 제목과 main 본문에서 후보 표현을 탐색하고, 직전 5편 본문 전체와 근접 주제를 검토했다.
- `배양`은 검진 후 확진검사·혈뇨 글에서 검사 예시로 등장했지만 담즙 검사 자료를 구분하는 독립 글은 없었다.
- `드레싱`은 가정간호 글에 서비스 예시로 등장했지만 항문수술 후 통원 처치비 설명은 없었다.
- `예약금`은 수술 취소 글에 구분 안내가 있었으므로 환급 요청·정산 근거 자료에 범위를 제한했다.
- MRI 기존 글은 비용·청구 또는 레켐비 모니터링이 중심이었다. 렌즈 카드 글의 카드 재확인 설명과 MRI 사전 기기 안전정보 확인은 범위를 나눈다.
- 재활 전원 글의 기관별 청구자료와 입원 중 타기관 의뢰·정산은 별개다. 기존 글의 짧은 설명과 충돌하지 않게 링크 문장을 검토한다.
- 제목만으로 기계적으로 중복 판정하지 않았다. 원고 작성 시에는 관련 문단을 다시 대조해 범위가 무너지면 기존 글 보완으로 전환한다.
- 발행 승인 후 각 편마다 출처·본문 근거 대조, PC/360/390px 실제 가독성, 공식 상세페이지 버튼, 내부링크 문맥 검수 후 순서대로 공개 검증한다. 수집 요청 접수와 실제 색인 완료는 구분한다.
