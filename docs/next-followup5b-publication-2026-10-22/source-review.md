# 공식 근거 검토

검토일: 2026-10-22. 기획 5편의 발행에 앞서 원문 범위를 확인했다.

1. 요양병원 처방약: 심평원 FAQ 47516의 실제 본문에서 진료의뢰를 받은 기관의 원내처방, 약 미보유 시 처방내역을 입원 중인 기관에 전달하는 절차를 확인했다. 요양병원 입원·진료의뢰 상황으로 한정한다. 모든 재활병원·임의 외출 진료·실손 지급에 일반화하지 않는다. `source-hira-medicine.txt`.
2. 수면 MRI 실비: 서울대암병원 MRI 원문에서 폐쇄공포증의 진료과 상담과 기관별 준비 안내를 확인했다(`source-snuh-mri.txt`). KB 공식 공개 PDF를 새로 내려받아 PDF 164쪽(인쇄 163쪽)의 20.01 단체상해보험 MRI 특약을 추출·렌더링·육안 확인했다. 치료 목적, MRI 범주, 조영제·판독료 포함 규정이 있으나 이 예시만으로 별도 진정 비용 전부를 포함 또는 제외한다고 결론내리지 않는다. 특정 2020년 상품의 예시라고 본문에 명시하고 항목별 적용 담보·제외 조항 확인 절차를 제공한다. 현행 계약 전체를 확인한 것으로 표현하지 않는다. 가입 세대별 한도표나 보편 가격·예상 보험금은 제시하지 않는다. `kb-mri-clause-page-164.png`, 내부 원문 `.deploy/followup5b-20261022/kb-contract.pdf`.
3. 회복기 재활: 심평원 제3기 지정 공고의 71개소·2026-03-01~2029-02-28 기간과 보건복지부 정책 페이지의 회복기 대상·시기 구분을 확인했다. 개별 기관의 최신 수용 여부를 확인한 것으로 소개하지 않는다. 일부 정책 페이지의 지정현황 표기는 공고보다 오래되어 기관 수 근거는 2026년 공고로 제한한다. 구체적인 환자 대상 인정이나 입원 기간을 판정하지 않는다. mw.go.kr 후보는 인증서 오류로 제외하고 정상 인증서의 moh​w.go.kr 공식 주소로 연결한다. `source-hira-designation.txt`, `source-rehab-policy.txt`.
4. 조영제 기록: 최초 후보 식약처 seq=70은 부작용 보고 방법이었다. 약물안전카드 직접 근거는 seq=71로 바로잡아 의료전문가가 기록하는 카드, 조영제 카드와 활용 안내의 실제 본문을 확인했다. 서울대병원 디지털 카드 게시물은 서비스의 기관별 예시로만 연결한다. 카드뉴스 이미지 전문 검독이나 전국 공통 발급 절차를 확인했다고 기록하지 않는다. 원인약 확정, 예방약·대체약 지정, 카드 발급 보장은 하지 않는다. `source-mfds-card.txt`.
5. 병원 폐업: 한국소비자원 2021년 의료기관 선납치료비 주의보 실제 본문에서 휴·폐업에 따른 잔여 할부금 항변과 통지, 환급과의 차이를 확인했다. 현행 접수 조건은 KB국민카드 공식 안내를 다시 확인하여 최초 20만원 이상·3개월 이상 할부·잔액과 예외(일시불 사후 분할납부 등)를 대조했다. 두 공식 자료의 표현 차이는 법상 기간·횟수와 카드 할부 개월 표기의 차이로 구분한다. 법령 링크는 제2조·제16조 및 시행령 제11조를 직접 대조할 확인처로 제공하고 법적 판단·환급을 확정하지 않는다. 이미 낸 대금과 남은 대금, 카드사 문의와 접수·심사 결과를 분리한다. `source-kca-prepaid.txt`, `source-kb-card.txt`. 현재 법령 전체를 조문별 검독했다는 주장은 하지 않는다.

## 편집·중복 검토

카탈로그 392편의 기존 제목·본문 검색과 가까운 기존 글 본문을 재대조했다. 이번 신규 질문은 처방약 수령, MRI 진정 비용 항목, 공식 재활기관 선택, 조영제 반응 기록, 폐업 시 잔여 할부금으로 각각 한정했다. 기존 글의 수납·서류·기기 안전·일반 약력·취소환급 안내와 구분한다. 실제 경로 충돌이 없음을 발행 직전에 재검사한다.

가상 예시는 가상으로 명시한다. 회사별 상품·절차를 보편 규칙으로 쓰지 않는다. 생성 이미지는 이해를 돕는 장면이며 실제 환자·공식 문서·기관 화면으로 소개하지 않는다.

## 이미지

built-in image_gen으로 썸네일 5장·본문 장면 10장을 새로 생성했다. 남색·파랑·흰색·노란색 포인트, 짧은 한글 제목과 실제 확인 행동을 지시했다. 썸네일 제목은 입원 중 처방약 / 수면 MRI 비용 / 회복기 재활병원 / 조영제 이상반응 기록 / 병원 폐업과 할부금이다. 본문 장면은 병동 상담·약 수령, MRI 상담·항목별 비용, 전원 상담·기관 비교, 이상반응 상담·카드, 계약 정리·카드사 문의다. 모든 장면에 실제 식별정보·약물 용량·허위 비용 숫자·기관 로고를 넣지 않도록 지시했다. 원본 경로는 내부 images.json, 최종 자산은 assets/images/에 저장한다. `image-contact-sheet.jpg`에서 15장 구성과 한글을 육안 검수했다.
