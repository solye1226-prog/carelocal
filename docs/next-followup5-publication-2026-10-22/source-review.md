# 출처·현행 기준 검토

검토일: 2026-10-22. 공개 원문을 직접 열고 본문 주장에 사용할 범위를 좁혔다. 검색 결과만으로 확인 완료 처리하지 않는다.

1. 입원 중 타기관 진료: 심평원 FAQ(2023-09-04 게시)의 실제 브라우저 본문을 확인했다. 기관이 의뢰한 진료의 청구 포함·기관 간 정산 범위로 사용하며 임의 방문·민간보험에 일반화하지 않는다. `source-hira-referral.txt`.
2. 치루 후 처치: 심평원 현재 공개 상세페이지에서 고시 제2018-3호 및 2018-04-01 시행 내용을 확인했다. 동일 문서의 변경 전 7회 제한과 구분한다. 추가 검색에서 후속 변경을 확인하지 못했지만 이를 모든 행위의 현행 무제한 보장으로 표현하지 않는다. `source-hira-dressing.txt`. 삼성화재 공개 PDF를 현재 다시 받아 확인했고 PDF 59쪽의 항문질환 비급여 제외 문구를 검토했다. 회사별 상품 예시이며 본인 계약의 급여·비급여·질환별 제외를 별도로 확인하도록 작성했다. `samsung-page-59.png`.
3. MRI: 식약처 seq=15300 가이드라인 게시 및 FDA 환자 안전 안내, HumanOptics의 제품별 안전 설명과 예외를 확인했다. 국내 특정 렌즈의 허가·사용조건을 검증한 것으로 취급하지 않는다. 일반 제품 정보 전달 절차에 한정하고 검사기관에 국내 사용설명서 확인을 요청하도록 작성했다. MR조건·대기기간·자장강도를 임의 지정하지 않는다.
4. 배양검사: 처음 기획한 질병관리청 복강내 감염 지침은 전문 의료진 대상이고 상업적 이용 및 진료심사 이용 제한이 있어 **원고 근거에서 제외**했다. 배양·동정·감수성 검사 역할은 분당서울대병원 미생물 분과 원문을 직접 확인하여 사용한다(`source-microbiology.txt`). 심평원의 배양 여부에 따른 감수성 검사 구분 안내를 확인했으며 수가 코드·정액 보험금으로 변환하지 않는다. 파티마병원 후보는 인증서 오류로 제외했고 경고를 우회하지 않았다. 검체별 필수검사·항생제 선택·감염 진단을 규정하지 않는다.
5. 예약금: 국가법령정보센터의 현행 소비자분쟁해결기준 제2025-14호(2025-12-18 시행), 본문 1~3조와 현행 별표2 PDF 63쪽 성형수술 표를 직접 확인했다. `source-current-consumer-standard.txt`, `consumer-standard-page-63.png`. 일반 질병수술에 성형수술 환급률을 확대하지 않고 계약·실제 진료·취소·공제 근거를 준비하는 절차로 제한했다. 한국소비자원 2025-06-11 선납진료비 안내와 현재 상담신청 페이지의 상담 후 피해구제·의료 전문 방문예약 안내를 확인했다. 과거 조정사례를 현재 공통 규정으로 사용하지 않았다.

공통: 보험사 자료는 회사·담보별 제출자료 예시이며 모든 계약의 지급 규칙이 아니다. 가상 예시는 가상으로 명시했다. 공식 상세페이지 버튼을 포함한다. 근거 자료의 전문을 공개 본문에 복제하지 않는다.

이미지: built-in image_gen으로 15장을 생성했다. 최종 WebP는 assets/images/에 배치한다. 프롬프트는 image-prompts.json에 기록했다. 썸네일의 한국어와 장면 15개를 image-contact-sheet.jpg에서 확인했고 허위 환자·공식 서류로 소개하지 않는다.
