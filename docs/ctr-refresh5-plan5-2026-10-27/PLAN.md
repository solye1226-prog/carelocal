# 추가 소재 5편과 최신 담보 키워드 기획

기획일: 2026-10-27. 상태: 기획 완료, 신규 원고 작성·발행 전.

## 선정 근거와 최신성

최근 네이버 유입은 담낭·백내장 수술 종수와 실비·청구서류에 집중돼 있다. 그 흐름에서 **기존 정액 수술비 → 질병군별 수술비 → 진단 이후 반복 치료비**로 확장한다. 아래 키워드의 검색량·CPC·경쟁 강도는 검증하지 않았으므로 ‘황금키워드 확정’으로 표현하지 않는다.

보험사 공식 사이트에서 실제 상품 판본과 심의기간을 확인했다.

- [KB 5.10.10 플러스 건강보험 공식 안내](https://www.kbinsure.co.kr/CG302290001.ec): 연만기갱신형(무배당)(26.09), 심의필 제2026-2848호(2026.09.29~2027.09.28). `116대질병수술비(I~VI)`, `2대질병(뇌, 심장) 주요치료비`를 확인했다. 증거 `kb-26-09-product.txt`.
- [KB 9회주는 암보험Plus 공식 안내](https://www.kbinsure.co.kr/CG302260001.ec): 무배당(26.07), 심의필 제2026-2189호(2026.08.10~2027.08.09). 통합암진단비, 남녀생식기암종 항암방사선치료비, 병원급별 3대질병 통원일당 구성을 확인했다. 증거 `kb-26-07-cancer.txt`.
- ‘최신’은 **이번에 확인한 2026년판 상품에 있는 담보**라는 뜻이다. 업계 최초 신설 또는 모든 회사의 최신 공통 담보라는 뜻은 아니다. 아래 글도 특정 상품 추천이 아닌 보장 구조·청구 확인 방법을 설명한다.
- 검색에서 발견한 KB 암치료보장집중형 페이지는 실제 열어 보니 심의기간이 2023~2024년이었다. 최신 근거에서 제외했다(`kb-older-product-not-current.txt`). CAR-T·NGS 키워드는 이 오래된 페이지 하나로 최신 담보라고 추천하지 않았다.
- 약관 버튼은 열기를 시도했지만 별도 원문 창을 확보하지 못했다. **상품 안내의 존재·판본·표시 조건은 확인했고 약관 전문의 조항·분류표 전체 검증은 아직 아니다.** 발행 전 해당 판본 약관 원문을 추가 확보하여 아래 확인 항목을 완료해야 한다. 안내에 없는 질병코드·금액·횟수를 임의로 작성하지 않는다.

## 1. 116대 질병수술비와 종수술비 차이, 같은 수술이면 둘 다 확인할까?

- 핵심 키워드: `116대 질병수술비 종수술비 차이`
- 세부 키워드: `116대 질병수술비 분류표`, `질병군 수술비 중복 청구`, `용종 수술 질병수술비`
- 제안 경로: `/surgery-benefit/116-disease-vs-tier-surgery-benefit`
- 독립 질문: 1~5종처럼 수술을 분류하는 특약과 특정 질병군을 대상으로 하는 수술비는 어떤 자료를 각각 봐야 하는가?
- 구성: 증권에서 두 특약을 구별 → 각 분류표 대조 → 실제 수술명 확인 → 동시수술·반복수술 규정 → 특약별 결과 확인.
- 공식 확인 범위: 26.09 안내에서 116대질병수술비(I~VI)와 반복수술 설명을 확인했다. 눈 레이저 수술의 60일 예외가 있으므로 ‘매번 무조건 지급’으로 일반화하지 않는다.
- 발행 전 약관 확인: 실제 116개 질병군 목록과 적용 코드, I~VI의 의미, 수술 정의, 지급 횟수와 두 담보의 각각 가입 여부. ‘116대’는 수술 종수 116종이라는 뜻으로 쓰지 않는다.
- 연결: `/surgery-benefit/type-surgery-benefit-claim`, `/surgery-benefit/surgery-classification`, `/claims/polyp-removal-claim-documents`.
- 중복 차이: 기존 글은 종수술비 분류·금액 또는 용종 청구서류다. 새 글은 질병군형 특약과 종수형 특약의 **두 분류표 대조**에 집중한다.

## 2. 뇌·심장 주요치료비, 진단비와 다른 지급 요건과 연간 한도 확인법

- 핵심 키워드: `2대질병 주요치료비 진단비 차이`
- 세부 키워드: `뇌 심장 주요치료비 연간 1회`, `주요치료비 진단 후 10년`, `중환자실 주요치료비`
- 제안 경로: `/diagnosis-benefit/brain-heart-major-treatment-vs-diagnosis`
- 독립 질문: 진단서를 낸 것과 실제 약관상 주요치료를 받은 것은 어떻게 구분하고 날짜를 관리하는가?
- 구성: 진단확정과 치료 행위 구분 → 최초 진단일·치료일 기록 → 보장 기간·연간 횟수 → 병원·약물·중환자실 조건 → 보험사 문의표.
- 공식 확인 범위: 26.09 상품 안내는 최초 진단확정일부터 10년간 연간 1회와 1년 이내 진단 시 50% 표시를 제공한다. **한 상품 예시**로만 다루며 실손 공제율이나 전체 시장 공통 조건으로 쓰지 않는다.
- 발행 전 약관 확인: 대상 질병 분류, ‘주요치료’ 목록, 연간 기준일, 치료별 지급 단위와 동일 연도 합산 규정.
- 연결: `/diagnosis-benefit/cerebrovascular-benefit-claim-documents`, `/standards/actual-vs-fixed-benefit`, `/claims/hospitalization-claim-documents`.
- 중복 차이: 기존 뇌혈관 글은 확정 진단의 근거 서류다. 새 글은 **진단 후 실제 치료와 시간·횟수 조건**이다.

## 3. 통합암진단비 전이암 포함, 재진단암과 같은 뜻일까?

- 핵심 키워드: `통합암진단비 전이암 재진단암 차이`
- 세부 키워드: `암종별 진단비`, `원발암 전이암 보험`, `통합암진단비 여러 번`
- 제안 경로: `/diagnosis-benefit/integrated-cancer-metastasis-vs-rediagnosis`
- 독립 질문: 새 장기에서 암이 확인됐을 때 원발암·전이암 구분과 해당 특약의 지급 그룹을 어떻게 대조하는가?
- 구성: 의료기록의 원발·전이 설명 → 특약의 암종 그룹 → 최초·반복 지급 조건 → 기존 지급 기록 → 추가 자료 요청.
- 공식 확인 범위: 26.07 안내에 전이암을 포함한 암종별 최대 9회 구성이 명시돼 있다. 최대 9회는 ‘누구나 9회 지급’ 또는 ‘아무 재발이나 매번 지급’이 아니다.
- 발행 전 약관 확인: 암 그룹, 전이암의 분류 원칙, 같은 그룹 재진단·잔존암·재발암 처리, 대기·감액·보장개시일. 광고의 최대 횟수보다 약관상 지급 단위를 앞세운다.
- 연결: `/claims/cancer-diagnosis-benefit-documents`, `/diagnosis-benefit/thyroid-cancer-benefit-claim`, `/claims/surgery-first-diagnosis-later-claim`.
- 중복 차이: 기존 암 청구 글은 전이암의 원발 확인이 필요할 수 있다는 일반 안내다. 새 글은 **통합암 그룹별 지급과 재진단 특약 비교**에 한정한다.

## 4. 남녀생식기암 항암방사선치료비, 중입자치료를 받으면 무엇을 확인할까?

- 핵심 키워드: `남녀생식기암 항암방사선치료비`
- 세부 키워드: `전립선암 중입자치료 보험 특약`, `중입자 방사선 치료비 서류`, `항암방사선 특약 질병 범위`
- 제안 경로: `/diagnosis-benefit/reproductive-cancer-radiation-rider-check`
- 독립 질문: 의료기관의 중입자 치료명과 보험 특약의 대상 암·방사선 정의가 어떻게 연결되는가?
- 구성: 특약명 → 진단명·치료명 대조 → 치료 완료·시행일 자료 → 반복 치료 횟수 → 기존 일반 항암방사선 담보와 구분.
- 공식 확인 범위: 26.07 상품 안내는 남녀생식기암종 항암방사선 보장에 중입자 등 기술을 포함한다고 설명한다. 이를 ‘모든 암·모든 중입자 치료 보장’으로 확대하지 않는다.
- 발행 전 약관 확인: 대상 암종과 분류표, 허가·치료 정의, 최초/연간/치료당 횟수, 의료기관 요건. 치료 적응증은 국가암정보센터·치료기관 공식 자료로 별도 확인한다.
- 연결: `/guides/heavy-ion-therapy`, `/guides/cancer-treatment-cost`, `/claims/cancer-diagnosis-benefit-documents`.
- 중복 차이: 기존 중입자 가이드는 치료·비용 개요다. 새 글은 **생식기암종 전용 방사선 특약의 대상 범위와 청구 확인**이다.

## 5. 3대질병 통원일당, 상급종합병원과 종합병원은 왜 따로 확인할까?

- 핵심 키워드: `3대질병 통원일당 병원급`
- 세부 키워드: `암 통원일당 종합병원`, `뇌혈관 통원일당 서류`, `같은 날 외래 통원일당`
- 제안 경로: `/diagnosis-benefit/three-disease-outpatient-daily-hospital-tier`
- 독립 질문: 실비 통원비와 정액 통원일당은 무엇이 다르고 병원 종별과 방문 목적을 어디서 확인하는가?
- 구성: 증권의 병원급 구분 → 의료기관 종류 확인 → 해당 질병 치료 목적의 방문 확인 → 같은 날·반복 방문 기준 → 자료 대조표.
- 공식 확인 범위: 26.07 안내의 암·뇌혈관·허혈성심장질환 통원일당과 상급종합병원/종합병원/일반병원 구성을 확인했다. 병원 이름의 ‘대학’·‘종합’만으로 종별을 추정하지 않는다.
- 발행 전 약관 확인: 직접치료 정의, 검사만 받은 날의 처리, 1일·연간 횟수, 동일일 복수 방문과 입원일 중 외래 규정. 현재 병원 종별은 HIRA·보건복지부 공식 자료로 확인한다.
- 연결: `/standards/actual-vs-fixed-benefit`, `/claims/medical-expense-claim-documents`, `/silbi/outpatient-prescription-diagnosis-code`.
- 중복 차이: 기존 실비 통원 글은 실제 의료비·처방·접수 자료다. 새 글은 **질병과 병원급에 따른 정액 통원일당 조건**이다.

## 중복 검토 기록

현재 카탈로그 432편을 기준으로 제목뿐 아니라 실제 `main` 본문을 검사했다. `116대`, `통합암`, `주요치료비`, `생식기`, `통원일당`의 직접 일치 글은 없었다. 가까운 암치료비 개요, 유병자 암·뇌 보장 개요, 뇌혈관 진단비 서류, 암 진단비 서류 및 중입자 가이드 본문도 대조했다. 새 기획은 위 차별 질문만 다루고 기존 일반 설명을 복제하지 않는다. 발행 직전에는 그 사이 새 글이 생겼는지 다시 확인한다.

## 작성 순서와 발행 기준

1→2→3→4→5 순서 권장. 먼저 1번으로 기존 수술비 유입과 연결하고 2·3번으로 진단비와 치료비의 경계를 넓힌다. 원고마다 한 회사·한 판본의 예시임을 표시하고 타사 일반화, 가입 권유, 예상 지급액 확정을 피한다. 회사별 약관 확보가 안 되면 해당 조건은 보류하며 확인되지 않은 정보를 채우지 않는다.

새 글은 아직 발행하지 않았다. 이번 요청의 신규 작업 범위는 기획이다.
