## 검증

- package.json의 check와 같은 구성으로 로컬 링크·canonical·Python 테스트·카탈로그·Node 분석 테스트 실행. PATH에 npm이 없어 Python과 번들 Node를 직접 사용했다.
- 로컬 HTML 701개 링크 검사 통과, sitemap457개 대표 URL 검사 통과, Python5/5, Node10/10, 카탈로그 일치 통과.

- 360·390·1280px에서 5편씩 실제 브라우저 렌더링과 가로 넘침 검사. document scrollWidth는 각 viewport보다 작음. 모바일 표의 항목 라벨 중복을 수정하고 갑상선 치료별 표의 카드 표시를 시각 확인.
