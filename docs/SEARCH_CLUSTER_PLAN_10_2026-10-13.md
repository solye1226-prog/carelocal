# 네이버 유입 주제에서 이어지는 후속 10편 기획

## 범위와 근거

사용자가 제공한 10월 12일 검색어 및 최근 7일·30일 통계에 기반한 기획이다. 검색어 목록은 도착 URL 목록이 아니므로 아래 기존 글을 실제 클릭된 URL로 확정하지 않는다. 키워드별 검색량·CPC·경쟁도는 미측정이다. 현재 카탈로그에서 관련 기존 글을 확인했다. 이 문서는 기획이며 새 글 발행이나 기존 공개 페이지 수정의 완료 기록이 아니다.

## 연결 원칙

- 기존 대표 글의 관련 답변 직후에 후속 글의 구체적인 질문을 링크한다. 모든 글에 같은 링크 목록을 붙이지 않는다.
- 새 글의 도입 또는 기준 설명에는 대표 글로 돌아가는 문맥상 링크를 배치한다. 일반 분류·서류 설명은 대표 글에서 확인하고 새 글은 독립된 상황에 집중한다.
- 아직 공개되지 않은 URL은 기존 페이지에 삽입하지 않는다. 본문 작성·검증과 공개 확인 후 연결한다.
- 제목과 주요 답변이 기존 본문과 겹치면 해당 글 보완으로 전환한다. 후보를 반드시 별도 URL 10개로 만들지는 않는다.
- KCD 진단코드, 진료행위 코드, 보험 수술분류표를 분리한다. 제품·행위명만으로 지급·종수·횟수를 단정하지 않는다.

## 글마다 제공할 결과물

1. 첫 부분에서 해당 상황에 대한 조건부 답변 제공.
2. 실제 병원 서류에서 확인할 필드와 계약에서 대조할 항목을 분리.
3. 주제에 필요한 비교표 또는 체크리스트. 모든 글에 동일 양식을 강제하지 않음.
4. 병원과 보험사에 물어볼 구체적인 질문 문장.
5. 해당 주장을 뒷받침하는 공식 상세 페이지 이동 버튼.
6. 대표 글 및 꼭 필요한 인접 글로만 연결.

## 검증과 성과 확인

작성 전에 기존 본문 검색 의도와 공식 근거를 대조한다. 발행을 진행하는 경우 프로젝트 지침의 로컬 검사, 실제 모바일 렌더링, 공개 본문 검증을 적용한다. 효과는 URL별 7일·28일 노출·클릭·CTR과 검색어를 비교하며 기존 대표 글과 후속 글을 함께 본다. 새 글의 노출이나 기존 글의 성장을 기획만으로 주장하지 않는다.
