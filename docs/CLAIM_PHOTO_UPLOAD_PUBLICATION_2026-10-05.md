## 로컬 검증

- npm은 PATH에 없어 동일 package.json check 스크립트를 번들 pnpm run check로 실행, 통과.
- HTML 168개 로컬 링크, 사이트맵 166개 canonical, Python 5개·Node 10개 테스트 통과.
- 카탈로그 141개, 새 항목 반영.
- 실제 브라우저 390x1000, 360x800, 1280x900 렌더링과 스크린샷 확인.
- 문서 가로 넘침 없음. 모바일 질문 버튼 높이 45.09px.
- 표는 헤더를 유지한 가로 스크롤, 모바일 안내 문구 및 키보드 포커스 제공.
- 질문 링크 대상 4개 존재, 오류 단계·파일 확인 링크 클릭 후 URL fragment 확인.
- 스크롤 뒤 이미지 3장 loaded=true, 자연 크기 1672x941 확인.
- /silbi/ 및 실비 청구서류 글에 유입 링크 추가.
- 기존 POSTING_GUIDELINES.md 변경과 다른 미추적 파일은 보존.

## 배포

- 콘텐츠 커밋 ca3ab69를 origin/main에 push했습니다. 배포 뒤 공개 URL에서 새 제목·본문·메타·canonical을 확인했습니다.
- 공개 390x1000, 360x800, 1280x900 실제 화면 확인. 모바일에서 새로 불러왔을 때 문서 가로 넘침 없음(각 375px, 345px; 스크롤바 공간 제외).
- 데스크톱에서 로드한 광고가 뷰포트 변경 뒤 기존 1200px 폭을 유지하는 현상을 관찰했습니다. 모바일 크기로 다시 로드한 뒤 넘침이 없음을 확인했습니다. 모바일 사용자 화면과 뷰포트 변경 잔여 광고 상태를 구분합니다.
- 공개 표 ArrowRight 키 입력 후 scrollLeft=40 확인, 헤더 표시 유지.
- 오류 단계 링크·접수 확인 링크 클릭 및 마지막 FAQ 펼침 확인(open=true).
- 공개 본문 이미지를 실제로 찾아 스크롤한 뒤 3장 모두 loaded=true, naturalWidth=1672, naturalHeight=941 확인.
- /silbi/ 목록과 /claims/medical-expense-claim-documents의 새 유입 링크를 브라우저에서 직접 확인했습니다.
- 공개 증거: docs/claim-photo-upload-public-mobile-2026-10-05.png 및 docs/claim-photo-upload-public-360-2026-10-05.png.
- 기존 자동 전면 광고가 본문 탐색 도중 표시됐고 광고 닫기 버튼으로 닫았습니다. 하단 앵커 광고도 관찰했습니다. 광고 콘텐츠를 클릭하거나 설정을 변경하지 않았습니다.
- urllib로 공개 파일 일치 검증을 시도했으나 HTTP 403이 반환됐습니다. 바이트 일치·공개 카탈로그 및 사이트맵 포함은 그 경로에서 검증하지 못했습니다. 공개 글·이미지·유입 링크는 브라우저로 확인했고, 카탈로그·사이트맵 일치는 로컬 검사로 검증했습니다.
- 작업용 탭을 닫고 뷰포트 설정을 원복했습니다. 색인 요청은 하지 않았습니다.
- 발행은 확인했으며 색인·노출·검색 순위·수익 변화는 미검증입니다.
