상태: 기획 후보. 이번 요청에서는 새 글을 작성·발행하지 않음.
선정 근거: 현재 카탈로그 367편의 제목과 본문을 대조하고, 기존 청구·보상 안내와 연결되는 별도 질문을 선정. 개별 후보의 검색량·광고 단가는 확인되지 않았으므로 황금키워드 또는 유입 증가를 확정하지 않음.

1. 실손보험금 연말정산 차감, 진료한 해와 받은 해가 다르면?
세부 키워드: 실손보험금 연말정산 의료비 차감 / 다음해 실비 수령
별도 질문: 보험금 지급 판단이 끝난 뒤 세액공제 대상 의료비와 귀속 연도를 어떻게 대조하는가.
기존 글과 차이: /silbi/hospital-receipt-vs-payment-certificate 는 병원의 납입확인서로 보험 청구가 가능한지 설명. 세액공제 계산·귀속 연도·수정신고가 본문에 없음.
구성: 진료·지출 연도와 보험금 수령 연도 기록 → 실손 수령액 조회 → 의료비 자료 대조 → 연도가 다르거나 정산 후 수령했다면 국세청 확인 절차. 정액 진단비를 실손 수령액과 임의 합산하지 않도록 적용 범위 확인.
연결 글: /standards/actual-vs-fixed-benefit, /silbi/hospital-receipt-vs-payment-certificate
공식 근거: https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7874&mi=6596
연도 차이 검토 근거: https://taxlaw.nts.go.kr/pd/USEPDA002P.do?ntstDcmId=200000000000010602
발행 전 추가 확인: 실제 귀속연도의 최신 국세청 신고 안내와 수정신고 적용 조건. 세금 환급액을 보장하지 않음.

2. 보험금 지급내역서 발급, 보험료 납입증명서와 무엇이 다를까?
세부 키워드: 보험금 지급내역서 발급 / 보험금 지급확인서
별도 질문: 이미 받은 보험금의 증빙을 어디서 발급하고, 조회 기간·담보·접수번호를 어떻게 확인하는가.
기존 글과 차이: /claims/claim-paid-no-bank-deposit 는 지급완료 뒤 입금이 안 보이는 문제, /standards/indemnity-proportional-compensation 은 산정액 대조가 중심. 증명서 발급 경로·납입증명서와의 차이를 다루는 독립 글은 없음.
구성: 제출처의 서류명 확인 → 보험사별 증명서 발급 메뉴 → 지급 연도·담보·접수번호 선택 → 누락된 항목 확인 → 필요한 범위만 제출. 계좌 입금내역·납입증명서와 구분.
연결 글: /claims/claim-paid-no-bank-deposit, /claims/insurance-claim-documents, /standards/indemnity-proportional-compensation
공식 근거: https://www.samsungfire.com/v2/html/customer/07/F_070_040_007.html
확인 내용: 삼성화재는 보험금지급내역서를 납입증명서와 별도로 안내하고 MY삼성화재의 증명서발행 절차를 소개. 타사 메뉴·발급 자격을 일괄 적용하지 않음.

3. 퇴사 후 개인실손 재개 신청, 중지했던 보험은 어떻게 이어갈까?
세부 키워드: 개인실손 재개 신청 / 단체실손 종료 후 재개
별도 질문: 퇴사 후 앞으로의 보장을 이어가기 위한 개인실손 재개 대상·시점·상품 선택·신청 자료 확인.
기존 글과 차이: /silbi/group-silbi-after-resignation-claim 은 재직 중 발생한 과거 병원비 청구가 중심. 재개 제도를 한 문단으로 언급하지만 신청 절차를 설명하는 글은 아님. 신규 글은 과거 청구서류 설명을 반복하지 않음.
구성: 개인실손이 실제 중지 상태인지 확인 → 단체실손 종료일 확인 → 적용 신청기한과 재개 상품 확인 → 접수·보장 개시일 확인. 해지·부활·전환과 구분.
연결 글: /silbi/group-silbi-after-resignation-claim, /standards/duplicate-vs-coinsurance, /standards/reinstatement-renewal-reenrollment
공식 근거: https://www.fsc.go.kr/po010105/79180?curPage=1
발행 전 추가 확인: 현재 보험사의 재개 대상·서식·상품 변경주기 조건. 과거 제도 발표의 조건을 모든 계약의 현행 규칙으로 단정하지 않음.

4. 해외 장기체류 실손보험료 환급, 귀국 후 어떤 서류를 준비할까?
세부 키워드: 해외 장기체류 실손보험료 환급 / 출입국사실증명서 실비 환급
별도 질문: 해외 진료비 보험금이 아니라 국내 실손의 보험료 환급을 위한 체류기간·계약·접수 자료를 확인.
기존 글과 차이: 해외 병원 영수증, 현지 약값, 귀국 후 국내 재진료 글들은 치료비 청구를 설명. 367편 본문에서 장기체류 보험료 환급을 다루는 독립 글은 없음.
구성: 해당 실손 계약과 환급 대상 조건 확인 → 출입국 기간 기록 → 보험사 지정 서식·증빙 확인 → 접수 및 환급 산정기간 대조. 여행자보험 의료비 청구와 구분.
연결 글: /claims/overseas-hospital-bill-documents, /silbi/post-travel-domestic-followup-silbi, /standards/premium-benefit-surrender-value
공식 근거: https://www.kbinsure.co.kr/CG604010201.ec
확인 내용: KB손해보험은 해외장기체류 실손 환급에 신청서·출입국사실증명서·신분증·통장 및 접수 경로를 안내. 해당 회사의 서류 예시이며 모든 계약에 자동 환급된다고 쓰지 않음.

5. 내보험찾아줌 숨은보험금 조회, 미청구 병원비도 확인될까?
세부 키워드: 내보험찾아줌 숨은보험금 / 미청구 병원비 조회 차이
별도 질문: 지급금액이 확정된 미청구 보험금 조회와, 본인이 아직 청구하지 않은 진료비를 구분하는 방법.
기존 글과 차이: 청구 방법·소멸시효·지급 지연 글은 치료비 접수와 심사 상태가 중심. 숨은보험금 통합조회 및 조회 결과의 범위를 설명하는 독립 글 없음.
구성: 공식 통합조회 경로와 본인인증 → 조회 결과의 보험사·보험금 종류 확인 → 미청구 치료비와 구분 → 해당 보험사 공식 청구 경로. 조회 결과가 없다고 미청구 진료비가 없다고 판단하지 않음.
연결 글: /claims/insurance-claim-method, /claims/insurance-claim-period, /standards/premium-benefit-surrender-value
공식 근거: https://www.fsc.go.kr/po010103/87270
확인 내용: 금융위원회는 숨은보험금을 지급금액이 확정됐으나 청구되지 않은 보험금으로 정의하고 공식 내보험찾아줌 경로를 안내. 미청구 의료비를 모두 자동 계산해 주는 서비스로 소개하지 않음.
