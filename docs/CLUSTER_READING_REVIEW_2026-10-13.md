# 최근 후속 10편 PC·모바일 가독성 개선

## 반영

배포 커밋 `0c784c5`. 최근 발행한 후속 10편에만 `assets/cluster-reading.css`와 `cluster-reading` 클래스를 적용했다. 제목·메타·canonical·공식 근거·이미지·대표 글 연결은 유지했다.

- PC: 본문 바깥 폭 최대800px, 제목34px·본문18px, 왼쪽 정렬과 문단 간격 적용. 이미지 최대600px.
- 모바일: 좌우20px 여백, 제목25px·본문17px, 본문 행간1.85. 짧은 핵심 답변과 후속 설명을 나누고 긴 본문은 문장 경계에서 문단을 분리.
- 표: PC에서는 3열 비교표, 모바일에서는 행별 카드로 표시하고 자료·쟁점 항목 이름을 붙였다.
- 메뉴: 확인할 항목·보험사 질문·준비 순서·공식 안내의 4개 앵커를 제공. 모바일은2열 메뉴, 각 버튼44px 이상.
- 질문 예시: 인용 박스의 여백·행간·배경을 조정. 공식 상세 버튼은1열로 표시해 설명문이 좁게 갈라지지 않도록 했다.

- `pnpm run check`: 링크·canonical·카탈로그와 기존 Python5개·Node10개 검사 통과.
- 로컬 새 글10편 × 360·390·1280px 이미지·버튼·가로 넘침 검사30/30 통과.
- 공개 새 글10편 × 동일3개 폭 검사30/30 통과.
- 읽기 전용 검증: 각 글390·1440px에서 본문폭·왼쪽 정렬·문단 길이·표 라벨·4개 바로가기 동작 확인. `CLUSTER_READING_PUBLIC_2026-10-13.json`에 결과 기록.
