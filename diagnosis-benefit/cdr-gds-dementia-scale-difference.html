CDR GDS 차이, 치매검사 결과지와 보험 약관 대조 방법

CDR GDS 차이는 치매 평가 결과지를 약관과 비교할 때 중요합니다. CDR·CDR-SB·GDS의 표기와 검사일을 구분하고 점수를 임의 환산하지 않는 확인 방법을 정리합니다.

보험사별 공식 홈페이지 확인하기

CDR GDS 차이, 점수의 이름부터 정확히 읽습니다

CDR GDS 차이를 찾는다면 결과지에 적힌 척도명 전체를 먼저 확인하세요. 둘 다 치매 평가에 쓰이지만 숫자를 서로 그대로 옮기거나, 한쪽 결과로 다른 쪽의 약관 조건을 채웠다고 판단할 수 없습니다. 검사를 통해 나온 평가와 의사의 진단, 민간보험 지급사유를 구분해야 합니다.

CDR·CDR-SB·GDS 결과지 비교

대한치매학회 2021 개정 진료지침(2022년 발표)의 국문 부록은 CDR과 GDS를 치매 중증도 평가에 사용되는 척도로 설명하며, CDR의 전체 등급과 영역 합산점수(CDR-SB)를 구분합니다. 이 글은 그 구분을 서류 확인에 활용하며 자가 채점표를 제공하지 않습니다.

GDS 약어만 보지 말고 검사명 전체를 확인하세요

약어가 같아도 문서에서 뜻하는 검사명이 다를 수 있습니다. 치매 평가에서 말하는 Global Deterioration Scale인지, 다른 평가도구인지 담당 진료팀에게 확인하세요. 결과지의 영문·한글 정식 명칭을 유지하면 보험사나 다른 병원에 전달할 때 혼동을 줄일 수 있습니다.

치매 진단비 약관과 대조하는 순서

  • 보험증권에서 실제 가입한 치매 특약명 찾기
  • 약관의 진단확정·인지기능 장애 정의 확인
  • 요구하는 척도·전문의·진단 자료 범위 확인
  • 결과지의 척도명·평가일·기록 범위 대조
  • 다른 척도 자료만 있다면 대체 인정 조항과 추가 자료 문의

특정 상품의 예시를 모든 치매보험에 적용하지 않습니다. 삼성화재 헤리티지 클래스 2601.3 약관 예시는 CDR을 포함한 치매 상태 정의와 진단 조건을 따로 둡니다. 본인 계약에서는 다른 척도나 조건이 쓰였는지 다시 확인하세요.

가상 예시: CDR-SB만 적힌 자료를 제출한다면

D씨 가족이 CDR-SB가 적힌 결과지만 가지고 있다고 가정합니다. 이를 임의로 global CDR로 바꾸어 청구하지 않고, 보험사가 확인하려는 척도와 병원에서 발급 가능한 자료를 문의합니다. 보험 요건을 맞추려고 새 검사를 임의로 요구하기보다 기존 기록으로 확인 가능한지 먼저 살핍니다. 실제 지급 사례가 아닙니다.

진단비 청구와 치료비 실비를 나눠 보기

치매보험 진단비 청구서류는 특약별 진단 자료를, 레켐비 실비 청구는 실제 치료비 자료를 다룹니다. 한 평가 결과가 약제 대상·보험금 지급을 모두 자동 결정하는 것은 아닙니다.
