홈 / 건강검진 가이드

Screening Guide

검진 결과에서 다음 확인까지 이어서 봅니다

건강검진은 질병을 확정하는 과정이 아니라, 추가 확인이 필요한 신호를 찾는 출발점입니다. 결과지 문구를 보고 어떤 진료과와 병원을 확인해야 하는지 단계별로 정리합니다.

국가 지원 검진 먼저 확인

National Checkup

연령대별 국가건강검진 항목

20대부터 70대 이상까지 공단이 지원하는 일반검진과 암검진 시작 연령을 정리합니다.

 Cancer Screening

국가암검진 확인 가이드

암검진 대상, 결과 통보, 추가검사 안내를 받았을 때 확인할 항목을 정리합니다.

 Endoscopy

위·대장내시경 준비

내시경 전 준비, 조직검사, 용종 절제 후 결과 확인 기준을 봅니다.

 Result Check

이상 소견 결과 확인

결절, 용종, 간수치, 혈뇨처럼 결과지에서 자주 보이는 표현을 정리합니다.

암 종류별 가이드로 이어보기

Thyroid

갑상선 결절과 갑상선암

초음파 결과, 세침검사, 추적검사 기준을 확인합니다.

 Lung

폐결절과 폐암 확인

저선량 CT, 추적검사, 폐암센터 확인 항목을 봅니다.

 Colorectal

대장 용종과 대장암

대장내시경, 조직검사, 추적검사와 병원 확인 기준을 정리합니다.

공식 확인처
